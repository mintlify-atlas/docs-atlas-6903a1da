T.O.P can restrict access to your instance using HTTP Basic Auth. When enabled, the browser displays a native username/password dialog before serving any page. The feature is powered by the `express-basic-auth` middleware, which intercepts every incoming request and validates the provided credentials against the `users` map in `config.js`.

<Warning>
  Passwords are stored in **plain text** in `config.js`. Do not use sensitive or
  reused passwords. Do not commit `config.js` containing real credentials to a
  public repository.
</Warning>

## Enabling password protection

<Steps>
  ### Set `challenge: true` in config.js

  Open `config.js` at the project root and flip the `challenge` field to `true`:

  ```js
  const config = {
    challenge: true,
    users: {
      interstellar: "password",
    },
  };
  export default config;
  ```

  ### Add users to the `users` object

  Each key is a username and its value is that user's password. You can define as many accounts as you need — all of them will be valid once the middleware is active:

  ```js
  const config = {
    challenge: true,
    users: {
      alice: "hunter2",
      bob: "correct-horse",
      charlie: "staple-battery",
    },
  };
  export default config;
  ```

  ### Start the server

  Start the server normally. T.O.P reads `config.js` at startup and activates `express-basic-auth` as soon as it sees `challenge: true`. No additional flags are required.

  <CodeGroup>
  ```bash pnpm — Linux / macOS
  pnpm start
  ```

  ```bash npm — Linux / macOS
  npm start
  ```

  ```bash bun — Linux / macOS
  bun start
  ```

  ```powershell pnpm — Windows PowerShell
  pnpm start
  ```

  ```powershell npm — Windows PowerShell
  npm start
  ```

  ```powershell bun — Windows PowerShell
  bun start
  ```
  </CodeGroup>
</Steps>

## What happens at startup

When password protection is active, the server logs a confirmation and prints every configured credential to the console so you can verify the setup at a glance:

```
🔒 Password protection is enabled! Listing logins below
Username: alice, Password: hunter2
Username: bob, Password: correct-horse
```

This output comes from `server.js` and only appears when `challenge` is set to `true` in `config.js`.

<Warning>
  Every username and password in the `users` map is printed to the server
  console in plain text on every startup. Avoid running T.O.P with real
  credentials in environments where the console output is captured by a logging
  service, CI system, or any other persistent store.
</Warning>
