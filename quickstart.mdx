T.O.P is a Node.js server application — getting it running locally takes nothing more than a clone, a dependency install, and a single start command. Follow the steps below and you will have a fully functional proxy, game catalogue, and tab system available at `http://localhost:8080` in just a few minutes.

<Warning>
  T.O.P requires a persistent Node.js process to operate. It **cannot** be deployed to static hosts such as Netlify, Cloudflare Pages, or GitHub Pages. Use a local machine, VPS, Docker container, or GitHub Codespaces instead.
</Warning>

## Prerequisites

Before you begin, make sure the following are available on your machine:

- **Node.js** `>= 16.0.0`
- **npm** `>= 7.0.0` — or an alternative package manager (pnpm or bun)

<Tip>
  **pnpm is recommended.** It is faster than npm, produces a deterministic lockfile, and is the package manager used by the Interstellar maintainers. Install it with `npm install -g pnpm` if you do not have it already.
</Tip>

## Setup Steps

<Steps>
  <Step title="Clone the Repository">
    Clone the Interstellar repository from GitHub and change into the project directory:

    ```bash
    git clone https://github.com/UseInterstellar/Interstellar
    cd Interstellar
    ```

    If you want the ad-free branch instead, use:

    ```bash
    git clone --branch Ad-Free https://github.com/UseInterstellar/Interstellar
    cd Interstellar
    ```
  </Step>

  <Step title="Install Dependencies">
    Install all required Node.js packages. Choose the command that matches your package manager:

    <CodeGroup>
      ```bash pnpm
      pnpm i
      ```

      ```bash npm
      npm i
      ```

      ```bash bun
      bun i
      ```
    </CodeGroup>

    This installs the Express server, both proxy engines (Ultraviolet and Scramjet), the Wisp WebSocket transport, and all other runtime dependencies listed in `package.json`.
  </Step>

  <Step title="Start the Server">
    Launch the T.O.P Node.js server:

    <CodeGroup>
      ```bash pnpm
      pnpm start
      ```

      ```bash npm
      npm run start
      ```

      ```bash bun
      bun start
      ```
    </CodeGroup>

    All three commands execute `node src/server.js` under the hood. Once the server is ready, you will see:

    ```
    🚀 Starting server...
    Serving from static/
    🌍 Server is running on http://localhost:8080
    ```

    The server listens on port **8080** by default. To use a different port, set the `PORT` environment variable before running the start command:

    ```bash
    PORT=3000 pnpm start
    ```
  </Step>

  <Step title="Open the Proxy in Your Browser">
    Navigate to [http://localhost:8080](http://localhost:8080) in any modern browser. The T.O.P home page will load with the search bar, game catalogue links, and theme controls all ready to use.

    To test the proxy, type any URL into the search bar and press Enter. The page will be fetched and rendered through the Scramjet engine (the default in v6) without leaving the T.O.P origin.
  </Step>
</Steps>

## Optional: Run the Production Build

The development server (`pnpm start`) serves files directly from the `static/` directory with no transformation. For a production deployment, run the build step first:

```bash
pnpm build
```

This executes `node src/build.js` and produces an optimised `dist/` directory that:

- **Obfuscates** all JavaScript using `javascript-obfuscator`
- **Minifies** all CSS with a custom build-time minifier
- **Hardens** the HTML pages
- **Randomises** the Ultraviolet and Scramjet proxy scopes per build, so encoded URLs are unique to your instance
- **Randomises** internal page routes and records them in `dist/.runtime/vendor-map.cjs`

After a successful build, `pnpm start` will automatically detect `dist/` and serve from there instead of `static/`.

<CodeGroup>
  ```bash pnpm
  pnpm build && pnpm start
  ```

  ```bash npm
  npm run build && npm run start
  ```

  ```bash bun
  bun run build && bun start
  ```
</CodeGroup>

## Optional: Enable Password Protection

To require a username and password before anyone can access the proxy:

1. Open `config.js` and set `challenge` to `true`. Add any username/password pairs you want under the `users` key:

   ```js config.js
   const config = {
     challenge: true, // Enable password protection
     users: {
       interstellar: "password", // username: 'password'
     },
   };

   export default config;
   ```

2. Start (or restart) the server normally:

   <CodeGroup>
     ```bash pnpm
     pnpm start
     ```

     ```bash npm
     npm run start
     ```

     ```bash bun
     bun start
     ```
   </CodeGroup>

The server reads `config.js` directly on startup. When `challenge` is `true`, it prints each registered username and password to the console and enables HTTP Basic Auth on every route. For full configuration details, see the [Password Protection](/configuration/password-protection) guide.
