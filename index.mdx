T.O.P is a high-performance, self-hosted web proxy built on Node.js. It combines the Ultraviolet and Scramjet proxy engines with a polished user interface, a library of 300+ games and apps, tab cloaking, and a full settings system — all deployable with a single command.

## Key Features

<CardGroup cols={3}>
  <Card title="Dual Proxy Engines" icon="shuffle">
    Switch between Ultraviolet and Scramjet backends. Both support XOR URL encoding with per-build key randomization.
  </Card>
  <Card title="300+ Games & Apps" icon="gamepad">
    A built-in catalogue of games and educational apps, served directly from the proxy with no external dependencies.
  </Card>
  <Card title="Tab Cloaking" icon="eye-slash">
    Disguise the tab title and favicon to look like any other page using the built-in about:blank cloaking system.
  </Card>
  <Card title="Password Protection" icon="lock">
    Enable HTTP Basic Auth with a single config flag to restrict access to authorized users only.
  </Card>
  <Card title="Rich Theme System" icon="palette">
    Choose from Catppuccin, Gruvbox, Tokyo Night, Nord, Synthwave, and more — or create your own.
  </Card>
  <Card title="Production Build" icon="wrench">
    A full build pipeline that obfuscates JS, hardens HTML, minifies CSS, and randomizes asset paths on every build.
  </Card>
</CardGroup>

## Get Running in 3 Steps

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/UseInterstellar/Interstellar
    cd Interstellar
    pnpm install
    ```
  </Step>
  <Step title="Start the server">
    ```bash
    pnpm start
    ```
    The server starts on `http://localhost:8080` by default.
  </Step>
  <Step title="Open your proxy">
    Navigate to `http://localhost:8080` in your browser, enter a URL or search term in the search bar, and start browsing.
  </Step>
</Steps>

<Note>
  T.O.P cannot be deployed to static hosts such as Netlify, Cloudflare Pages, or GitHub Pages. It requires a Node.js server environment. See the [Deployment](/deployment/server) section for supported platforms.
</Note>
